    Why "normal" can be trusted

    The satellites changed. The fires didn't.

    MODIS, the sensor behind NASA's fire record since 2000, is retiring. Its successor VIIRS sees far smaller fires, so the two can't be compared directly. Without a way to connect them, the first decade of fire history is lost. FireCal connects them, so it no longer matters which sensor a hotspot came from.

    The proof

    Tested on years it had never seen

    For every year since 2012 we hid that year, trained on the rest, and asked FireCal to rebuild it from the old MODIS sensor alone. Then we checked against what VIIRS actually saw.

    How it works

    Four steps from raw detections to one record

    1. Same grid for every satelliteEach detection is placed on a 1 km grid. A square counts once per satellite per day, so a sharper sensor isn't rewarded for seeing one fire as many dots.
    2. Missing is never zeroA month counts only if the satellite was operating and every day was retrieved. Gaps stay gaps.
    3. Learn the translationFrom 2012 to 2026, when both sensors flew, a machine-learning model learns what VIIRS would have seen given what MODIS saw.
    4. Rebuild the pastBefore 2012 the calendar shows that VIIRS-equivalent estimate, with a range. From 2012 it shows what VIIRS actually observed.
