    Problem

    MODIS and VIIRS records don't match

    VIIRS (since 2012) detects smaller fires than MODIS (since 2000), so it reports more burning for the same area. MODIS is retiring. Without a correction, records before 2012 can't be compared with today.

    Method

    How it works

    1. One gridEvery detection goes on a 1 km grid. A square counts once per satellite per day.
    2. Gaps stay gapsA month counts only if every day was retrieved.
    3. Learn the conversionA model learns MODIS to VIIRS from 2012–2026, when both flew.
    4. Rebuild 2000–2011Earlier months show the VIIRS-equivalent estimate with a likely range.
